# CourseCraft Agent Rules

- Work on `working-branch` by default.
- Keep `main` stable; merge from `working-branch` into `main` periodically when requested.
- After every source change, update graphify for the project before committing.
- Commit and push completed changes.
- Do not add Codex, ChatGPT, OpenAI, or any assistant identity as a co-author.
- Do not include `Co-authored-by` trailers in commit messages.
